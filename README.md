# Math Quiz Game (C++)

A console-based **Math Quiz Game** developed in **C++** as part of my programming learning journey.

The game generates random arithmetic questions with different difficulty levels and operation types. It evaluates the player's answers, keeps track of the score, and displays the final result.

## 🚀 Features

- Choose the number of questions.
- Select the difficulty level:
  - Easy
  - Medium
  - Hard
  - Mixed
- Select the operation type:
  - Addition
  - Subtraction
  - Multiplication
  - Division
  - Mixed Operations
- Random question generation.
- Instant answer validation.
- Score tracking.
- Final pass/fail result.
- Play multiple games without restarting the application.
